# 需求文件

這裡放專案所有的需求文件。

## 檔名規則

`REQ-<三位數編號>-<英文短名>.md`，例如 `REQ-001-player-movement.md`。

- 編號依建立順序遞增，不重複使用。
- 新需求一律複製 [`_TEMPLATE.md`](_TEMPLATE.md) 開始寫。
- 驗收方式：單元測試通過後，實作者提供文字總結給使用者確認，使用者確認後即通過驗收。

## 狀態

| 狀態 | 意義 |
| --- | --- |
| 草稿 | 還在撰寫，內容可能變動 |
| 確認 | 內容定案，可以開始實作 |
| 實作中 | 開發進行中 |
| 完成 | 單元測試通過，使用者已確認文字總結 |
| 擱置 | 暫停或取消，保留紀錄 |
